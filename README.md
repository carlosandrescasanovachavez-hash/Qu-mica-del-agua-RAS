# Química del agua RAS

Guía interactiva de calidad de agua para sistemas de recirculación (RAS) en cultivo de salmón.

Abre `index.html` en el navegador.

## Versión en inglés / English version

- `index.html` y `bomba-de-calor.html` son las páginas en español (originales).
- `en.html` y `bomba-de-calor-en.html` se generan automáticamente. Después de editar las páginas en español, ejecuta:

```
python3 tools/build_en.py
```

Las traducciones están en `tools/es_en.json` (guía) y `tools/es_en_bomba.json` (bomba de calor). Si agregas texto nuevo en español, agrega también su traducción ahí.
